# ADR-029：前端行為鎖——固定輸入、完整輸出、逐字元比對

- 狀態：**Accepted**（2026-09-19 起草並於同日實作，D11 的續章）
- 關聯：[ADR-026](ADR-026-frontend-modules.md) 前端拆成 ES module、[ADR-027](ADR-027-injected-runtime-state.md) 後端狀態改注入與**它明說沒兌現的那一段**、[ADR-028](ADR-028-declarative-acceptance.md) 同一套「固定輸入 → 完整輸出 → 逐位元組比對」的差分收據
- 依據：[docs/REVIEW-2026-09-16-project-assessment.md](REVIEW-2026-09-16-project-assessment.md) §4.4

## Context

ADR-026 承諾「`state.js` 的全域在 D11 改成注入」。D11 做了後端那一半（`core/runtime_state.py`），
前端那一半**沒有做**，理由寫在 ADR-027 的 Consequences：

> 前端的 49 個共享值全部經由渲染函式的閉包讀寫，要改成注入等於重寫十個分頁模組的函式簽章，
> 而且沒有等價於 pytest 的前端測試可以證明「行為不變」——只有一支 Playwright 煙霧測試。
> 在能證明之前不動它，比動了再說「應該沒壞」誠實。

那句話擋住了一次沒有證據的改動，但它同時也是一張欠條：**只要證據一直不存在，那段程式碼就
永遠動不了**。這份 ADR 是去把證據做出來，不是去繞過它。

現有的 `scripts/dashboard_smoke.py` 不夠。它證明的是「六個分頁開得起來、console 不吵、
1440／494 px 不水平溢出、字典切得動」——全部是**存在性**命題。把某個渲染函式的判斷式對調、
把 `esc()` 拿掉、把一個共享預設值從 `"day"` 改成 `"week"`，煙霧測試**照樣全綠**。
重寫十個模組的函式簽章需要的是相等性命題：**同樣的資料進去，畫出來的 DOM 一模一樣**。

## Decision

照 D12 差分收據的同一條路做一支 `scripts/dashboard_dom_lock.py`：**固定輸入 → 完整輸出 →
逐字元比對**。差別是 D12 的 harness 需要改動前的檔案才跑得動，所以用完就丟；這一支的輸入是
錄下來的罐頭，**可以留在 repo 裡反覆跑**。

### 1. 輸入固定到「不需要伺服器、不需要資料庫、不需要網路」

`record` 會開一份臨時的 `OMNICONTEXT_HOME`、灌進一份**有內容的**種子資料、用 `TestClient`
當後端、用真的 Chromium 當前端，把開機時前端真的問過的每一個 `/api/**` 連同回應錄下來
（目前 35 個端點）。之後的 `check` 只重播罐頭：靜態檔從 `web/` 讀，API 從
`tests/fixtures/dashboard_dom/api/` 讀，**沒有伺服器、沒有資料庫、沒有對外連線**。

錄製時會把臨時 home、checkout 路徑與使用者家目錄換成固定字串（`/omni/home` 等），
語料才不會綁在錄製那台機器上；有一支測試守著這件事。

### 2. 所有會飄的東西都釘死

| 會飄的東西 | 怎麼釘 |
| :--- | :--- |
| 時間（「3 小時前」） | 瀏覽器 `Date` 凍在 `meta.json` 的 `frozen_clock`；`Date.now()` 一起凍 |
| 時區 | 釘 UTC。後端的時間欄位是 naive datetime，JS 的 `new Date("…")` 當本機時間解析，兩邊得同一個時區才對得起來 |
| 亂數 | `Math.random` 換成固定種子的線性同餘 |
| 輪詢與輪播 | `setInterval` 回傳遞增的假 id 但不排程（**回傳真值**——程式碼會用 `if (state.xTimer)` 判斷有沒有在輪詢，回 0 會改到分支） |
| 語言 | 開機前寫進 `localStorage`，兩種語言各錄一輪 |
| 視窗尺寸 | 1440×2400，一次畫完不必捲動 |

### 3. 一次開機只拍一個分頁

第一版是「開一次、依序點六個分頁、各拍一張」。穩定性檢查當場抓到 **`tab-assistant`
在後面幾個分頁被點過之後又變了**——也就是那張快照的內容取決於它是第幾個被拍的。
與其去追是誰跨分頁改了誰（那是另一件事），不如讓每張快照只回答一個乾淨的問題：
**「開機之後打開這個分頁，畫出來是什麼？」** 代價是十二次開機（約一分鐘），換到的是
每張快照都獨立，而且**那個跨分頁耦合仍然被記著**，沒有被掃到地毯下。

### 4. 輸出**不做任何 normalize**

六個分頁 × 兩種語言的 `innerHTML` 原樣寫進 `tests/fixtures/dashboard_dom/panes/*.html`，
比對是逐字元相等。**normalize 會把差異藏起來，而這支工具的全部價值就是不藏**——
一個會折疊空白的美化器，正好會吃掉「某個地方少了一個空格」這種最典型的渲染回歸。
差異難讀的問題用工具解（`check` 會印出第一個不同的字元位置與前後文），不用降低精度解。

### 5. 每次拍完都要證明「它已經不動了」

拍一張、靜置 600ms 再拍一張，兩張不一樣就**直接失敗**並說是哪個分頁。
不穩的快照比沒有快照更糟：它會變成間歇性紅燈，然後被當成雜訊關掉。

### 6. 種子資料必須會咬人

第一版種子全是乖巧的中文。拿它當鎖，把 `esc()` 的 `.replace(/"/g, "&quot;")` **整行刪掉**，
十二張快照**一個字元都沒變**——因為沒有任何一筆資料含雙引號。跳脫是 XSS 的第一道門，
鎖不住它就沒資格叫行為鎖。

現在每一條會被渲染的資料通道（專案摘要、未結事項、AI 對話、commit 訊息、視窗標題、
秘書筆記、PR 標題、RAG 對話與資料夾名、日報 Markdown、行事曆標題）都帶一筆
`"雙引號" <b>粗體</b> & '單引號' <img src=x onerror=1>`。同一個突變現在會讓四張快照變紅。

### 7. pytest 守的是「語料還有沒有資格當鎖」

真正的比對要開瀏覽器，預設不在 `pytest` 裡跑（設 `OMNI_DOM_LOCK=1` 才跑那一支）。
但**最容易爛掉的不是比對，是語料**：拿一個空資料庫重錄一次，十二張快照全變成空殼，
`check` 依然全綠——鎖還在，但它什麼都不鎖了。

`tests/test_dashboard_dom_lock.py` 的十項在沒有瀏覽器的情況下守這件事：快照不得過薄、
必須含得到種子資料的痕跡（挑的是兩種語言都一樣的**資料值**，不是會被字典翻掉的介面字）、
必須含跳脫過的惡意字串且不得含未跳脫的注入、`&quot;` 至少要在四張快照裡看得到、
分頁矩陣必須與 `index.html` 的 `data-tab` 對得上（**加了第七個分頁沒擴充鎖就會紅**）、
語料不得夾帶機器路徑、`meta.json` 的六個釘子一個都不能少。

## 它不鎖什麼（先講清楚，免得把它當成它不是的東西）

- **不鎖輪詢後的更新**：釘的是第一次渲染，`setInterval` 被關掉了。
- **不鎖互動**：只走「開機 → 打開一個分頁」。按鈕、表單、對話框之後的渲染不在裡面。
  真要動到那些路徑的重構，這支鎖**不夠**，要先把對應的互動加進 `capture_pane`。
- **不鎖樣式**：比的是 DOM 不是像素，CSS 改了它不會紅。
- **不鎖後端**：API 回應是罐頭，後端行為由 `pytest` 管。
- **預設不在 CI 跑**：跟 `dashboard_smoke.py` 一樣是要用手跑的收據。把它排進 GitHub Actions
  需要在 runner 上裝 Chromium，那是另一個決定，**沒有做就不假裝有做**。

## Consequences

**好的**：

- ADR-027 欠的那張條子有東西還了。`state.js` 改成注入現在**有辦法證明行為不變**：改之前跑
  `update`，改之後跑 `check`，十二張快照逐字元相同才算數。
- 得到一件原本沒有的東西：**在沒有瀏覽器的機器上也跑得動的跳脫回歸測試**。
  `esc()` 壞掉不再只是「希望有人 code review 看到」。
- 那個跨分頁耦合（打開別的分頁會改到 `tab-assistant`）被記錄下來了，而不是被一張
  剛好在對的時機拍到的快照蓋掉。

**代價，如實記下**：

- **語料是機器產物，而且不小**：35 個 JSON ＋ 12 個 HTML，約 340 KB 進 repo。
  改前端的人會看到快照一起變——那正是重點，但 review diff 會比較吵。
- **重錄需要能跑後端的環境**（`record` 會建臨時資料庫並跑 migration）。只做 `check` 不用。
- **時鐘釘在錄製的那一刻**，換機器重錄會整批變。這是釘死時間換來的，不是缺陷，但要知道。
- **覆蓋面是「開機後的第一畫面」**，不是整個前端。上面「不鎖什麼」那一節就是它的邊界；
  不要拿它當「前端有測試了」的通行證。
- **十二次開機約一分鐘**。所以它預設不在 `pytest` 裡，也就意味著**它不會自己提醒你跑它**。
  這是這支鎖目前最大的弱點，寫在這裡而不是藏起來。

## 怎麼證明這支鎖真的鎖得住

三個突變，各自單獨套用、跑 `check`、還原：

| 突變 | 結果 |
| :--- | :--- |
| `esc()` 不再跳脫雙引號（刪掉 `.replace(/"/g, "&quot;")`） | 4 張快照變紅（projects／summaries × 兩語言） |
| `statusLabel` 的階梯最前面插一條先成立的分支（純順序，字串沒動） | 2 張快照變紅 |
| `state.js` 的共享預設值 `summaryView` 從 `"day"` 改成 `"week"` | 2 張快照變紅（各多 2,240 字元） |

第一個突變在**種子變兇之前是抓不到的**（十二張快照一個字元都沒變）——這件事寫在上面第 6 節，
因為它正是這支鎖差點變成裝飾品的地方。

守門測試自己也驗過會壞：把種子清空重錄一次，十項裡有**四項變紅**
（快照過薄、看不到種子資料、看不到跳脫過的字串、`&quot;` 不見了），
不是靠「應該會紅」推論的，是真的跑出來的。
